# Dos Mundos

Juego cooperativo de terror en 3D para dos personas: **Vista** ve las cámaras pero no puede hablar y se comunica con señas de la Lengua de Señas Mexicana; **Oído** juega con los ojos vendados, guiado por audio espacial 3D, el radio y una pulsera háptica, mientras un monstruo caza por el ruido.
